# How Many Tabs Do You Have Open?

An entry for the make.fun bounty "How Many Tabs Do You Have Open?".
`main.py` (Python, standard library only) writes exactly one number,
digits only, to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`): three characters, no
newline, no punctuation, nothing else, as the gate requires.

The final content of `entry.txt` is:

```
437
```

437 tabs: far above the 10–30 most people would guess, still under
the ~500 line where a real browser session survives, and ending in
the uneven 7 that a real count ends on — nobody invents a 7, you
arrive at one. It is a semester of lectures, listings, deadlines
and half-read articles, one tab per thought, none ever closed:
tab guilt in three digits. Thirteen candidates were drafted and
weighed (see `CANDIDATES.md`); the first-pass pick was 342, and
the refinement pass moved it to 437 for more surprise without
losing believability.
